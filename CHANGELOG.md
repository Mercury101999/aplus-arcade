# Changelog

## 1.0.0 - 2026-11-18

- Original practice bank for CompTIA A+ Core 1 (220-1101) and Core 2 (220-1102), 145 questions across the nine official domains.
- Ten-question rounds filtered by exam, domain, or mixed, with the explanation right after each answer.
- Confidence rating (Guessing, Somewhat, Sure) recorded before the result, including a count of confidently wrong answers.
- Review queue for misses and low-confidence correct answers, and a Retry missed round.
- XP, levels, a daily streak, and badges, with motion disabled when the device requests reduced motion.
- Progress screen for accuracy, weak domains, calibration, and a confirmed reset.
- Progress stored on the device with AsyncStorage. No account and no backend.
- Jest tests, ESLint, a typecheck, and GitHub Actions workflows for CI and GitHub Pages.
